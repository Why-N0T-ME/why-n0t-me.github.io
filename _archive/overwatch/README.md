# Overwatch 테마 보관

연구 노트형 디자인으로 바꾸기 전의 Overwatch 테마에서 쓰던 파일 중, 새 테마에서 쓰지 않는 것을 모아 둔 폴더입니다.
`_` 로 시작하는 폴더라서 Jekyll 이 빌드에 포함하지 않습니다.

| 파일 | 설명 |
|---|---|
| `ow.css`, `ow.js` | 예전 스타일과 스크립트 (전리품 상자, 설정 패널 포함) |
| `loot.html`, `study_fields.yml` | 전리품 상자 화면과 분야 목록 |
| `img/categories/` | 카테고리 일러스트 6장 |

전체 예전 테마(레이아웃 포함)는 git 기록에 그대로 남아 있습니다.
`main` 브랜치의 `d3ece0b` ("오와리") 커밋을 보면 됩니다.
