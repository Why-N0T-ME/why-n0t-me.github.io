## 문제 코드

```python
from Crypto.Util.number import getPrime, isPrime, bytes_to_long
import secrets, os
from math import gcd
from secret import flag

def gen(m, k):
    while True:
        q = 2**1023 + secrets.randbelow(2**1023 + 1)
        r = getPrime(16)
        t = secrets.randbelow(99) + 2
        p = q * r ** t + k

        if isPrime(p):
            c = pow(m, r, p)
            break
    return p, r, c

m1 = bytes_to_long(os.urandom(16))
m2 = bytes_to_long(os.urandom(16))

print("Plz Wait...", flush=True)

while True:
    p1, r1, c1 = gen(m1, 2)
    p2, r2, c2 = gen(m2, 1)
    if gcd(p1 - 1, r1) != 1 and gcd(p2 - 1, r2) == 1:
        continue
    break

print(f"{p1 = }")
print(f"{r1 = }")   
print(f"{c1 = }")      
ans1 = int(input("m1? > "))
if ans1 != m1:
    exit(0)

print(f"{p2 = }")
print(f"{r2 = }")   
print(f"{c2 = }")   
print(f"m2 = {str(m2)[:3]}...")
ans2 = int(input("m2? > "))
if ans2 != m2:
    exit(0)

print(flag)
```

## 코드 분석

### 1. 목표

플래그를 얻으려면 중간에 `exit(0)`에 걸리지 않고 끝까지 가야 한다.
그러려면 입력값이 각각 `m1`, `m2`와 같아야 하므로, 결국 **m1, m2를 알아내는 것**이 목표다.

- `m1` : `os.urandom(16)`으로 만든 랜덤 16바이트(128비트) 정수
- `m2` : 동일한 방식으로 만든 랜덤 16바이트(128비트) 정수

### 2. 서버 동작 흐름

1. `m1`, `m2` 생성
2. `gen()`으로 `(p1, r1, c1)`, `(p2, r2, c2)` 생성 (조건에 따라 재생성)
3. `p1`, `r1`, `c1` 출력 → `m1` 입력 → 틀리면 종료
4. `p2`, `r2`, `c2`와 **`m2`의 앞 3자리** 출력 → `m2` 입력 → 틀리면 종료
5. 둘 다 맞으면 `flag` 출력

두 번째 값들(`p2`, `r2`, `c2`, `m2`의 앞 3자리)은 `m1`을 맞춰야 받을 수 있다.

### 3. `gen(m, k)` 분석

`m`, `k`를 입력으로 받아, `p`가 소수가 될 때까지 아래 값들을 반복해서 새로 뽑는다.

$$ q = 2^{1023} + x \quad (0 \le x \le 2^{1023}) $$

$$ r = \text{16비트 소수} $$

$$ t = x \quad (2 \le x \le 100) $$

$$ p = q \times r^t + k $$

`p`가 소수이면 다음 값을 계산하고 `(p, r, c)`를 반환한다.

$$ c = m^r \pmod{p} $$

| 구분 | 호출 | 생성되는 소수 |
|------|------|---------------|
| 1단계 | `gen(m1, 2)` | $$ p_1 = q_1 \times r_1^{t_1} + 2 $$ |
| 2단계 | `gen(m2, 1)` | $$ p_2 = q_2 \times r_2^{t_2} + 1 $$ |

- 우리가 아는 값 : `p`, `r`, `c` (+ `m2`의 앞 3자리)
- 모르는 값 : `q`, `t`, `m`
- `q` 자체는 소수가 아니라 그냥 1024비트 정수다.

### 4. 메인 루프 조건 분석

```python
while True:
    p1, r1, c1 = gen(m1, 2)
    p2, r2, c2 = gen(m2, 1)
    if gcd(p1 - 1, r1) != 1 and gcd(p2 - 1, r2) == 1:   # 조건 A and 조건 B
        continue
    break
```

- `gcd(p1 - 1, r1) != 1` **이고** `gcd(p2 - 1, r2) == 1` 이면 `continue` → `p`, `r`, `c`를 다시 생성
- `gcd(p1 - 1, r1) == 1` **이거나** `gcd(p2 - 1, r2) != 1` 이면 `break` → 값 확정

#### 이 조건이 실제로 하는 일

`p`의 형태를 대입해서 보면 두 gcd 값은 항상 정해져 있다.

- $$ p_1 - 1 = q_1 r_1^{t_1} + 1 \equiv 1 \pmod{r_1} $$ 이므로 $$ \gcd(p_1 - 1, r_1) = 1 $$
- $$ p_2 - 1 = q_2 r_2^{t_2} $$ 이므로 $$ r_2 \mid p_2 - 1 $$ 이고 $$ \gcd(p_2 - 1, r_2) = r_2 \ne 1 $$

그래서 `if` 조건은 항상 False이고, 루프는 첫 번째 시도에서 바로 `break` 된다.
즉 이 조건문은 사실상 아무 영향이 없다.

## 풀이

메인 루프에서 사실상 p,r,c는 gen(m,t) 한번 호출해서 값이 정해지고 p,r,c 값을 주기 때문에 모르는 값은 q, t, m 뿐이다.

- $$ c_1 = m_1^{r_1} \pmod p $$

이므로
- $$ m_1 ^ {r_1} = c_1 - p_1 \cdot k \quad where ( 1 \le k \le p_1 ) $$
