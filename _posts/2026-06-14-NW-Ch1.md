## Cisco Packet Tracer Intro

### Logical Mode VS Physical Mode
* **Logical Mode:** Focuses on the network's logical structure and connectivity. It allows you to design the topology, configure device settings, and define networking mechanisms — such as IP subnetting and routing protocols — independent of the devices' physical locations.
* **Physical Mode:** Visualizes the network within a realistic physical environment. Based on the logical design, you can install and deploy network devices across specific geographical scales — such as cities, buildings, and wiring closets — while managing physical constraints like rack placement and cable runs.

### 1. Logical Mode Topology Overview (LAN Structure)

![LAN](/assets/img/posts/CISCO-PT/LAN.png)
*Figure 1-1. Cisco Packet Tracer Logical Mode Local Area Network (LAN) Topology*

#### A. Network Architecture
* **Central Switch:** A Cisco Catalyst 2960 switch serves as the backbone of the LAN, handling high-speed data switching and facilitating internal communication across all connected devices.
* **End Devices:** User terminals — including PCs, Laptops, and Servers — are directly connected to the switch, forming a single local broadcast domain.
* **Wireless Access:** A generic Access Point (AP-PT) is connected to the switch to extend network availability, enabling mobile devices such as smartphones to join the LAN via Wi-Fi.

#### B. Key Technical Points & Subnet Planning
A standard Class C private IP block was implemented using static IP addressing:
* **Network Address:** `192.168.1.0 /24` (Subnet Mask: `255.255.255.0`)
* **Device IP Allocation:**
  * Server1: `192.168.1.10`
  * PC2: `192.168.1.21`
  * Laptop1: `192.168.1.22`
  * Smartphone0: `192.168.1.23`
* **Link Status:** All port link indicators between the switch and connected devices are **Green**, confirming that cabling and interfaces are fully operational.
* **Local Connectivity:** ICMP reachability (ping tests) has been verified successfully among all hosts within the local network.

### 3. Wiring Closet Infrastructure: Rack, Table, and Shelf

![PhysicalMode](/assets/img/posts/CISCO-PT/Physicalmode.png)
*Figure 3-1. Physical Wiring Closet Environment*

Inside the wiring closet, equipment is organized into three primary structures based on form factor and operational role:
* **Rack:** A standardized frame used to mount and secure enterprise-grade network devices such as *Routers, Switches, Servers, and Access Points*.
* **Table:** A flat workspace for placing and managing end devices such as *PCs and Laptops* during setup, testing, or local administration.
* **Shelf:** A storage component used for standalone devices without rack-mount ears, or for keeping backup and non-operational hardware organized when not in active use.

### 4. Device Connection Media Summary
Once network devices are installed and powered, they must be connected to end devices using the appropriate media:

* **Ethernet Cable:** The standard copper straight-through cable for LAN connections between end devices and switches or routers.
* **Console Cable:** Used for initial out-of-band management and direct configuration of network equipment.
* **USB Cable:** Supports modern console access and connects USB-compatible peripherals.
* **Fiber Optic:** Provides high-speed, long-distance data transmission for backbone links.
* **Serial Cable:** Used for WAN connectivity, typically between routers across different networks.
* **Coaxial:** Used for cable broadband connections, such as linking a cable modem to a service provider.
* **Wireless:** Enables cordless connectivity via Wi-Fi or cellular networks for smart devices and wireless clients.
