## 서비스 분석
### 문제
```python
@APP.route('/upload', methods=['GET', 'POST'])
def upload_memo():
    if request.method == 'POST':
        filename = request.form.get('filename')
        content = request.form.get('content').encode('utf-8')

        if filename.find('..') != -1:
            return render_template('upload_result.html', data='bad characters,,')

        with open(f'{UPLOAD_DIR}/{filename}', 'wb') as f:
            f.write(content)

        return redirect('/')

    return render_template('upload.html')
```
{: file="upload.py"}
`/upload`는 "**..**"가 filename에 들어있을 시에 *bad characters,,*를 출력한다. 즉, upload를 통해서는 상위디렉터리로 이동이 불가능하다.

```python
@APP.route('/read')
def read_memo():
    error = False
    data = b''

    filename = request.args.get('name', '')

    try:
        with open(f'{UPLOAD_DIR}/{filename}', 'rb') as f:
            data = f.read()
    except (IsADirectoryError, FileNotFoundError):
        error = True
    return render_template('read.html',
                           filename=filename,
                           content=data.decode('utf-8'),
                           error=error)
```
{: file="read.py"}
read_memo() 함수는 /uploads/{filename}을 읽어 data에 넣고 read.html을 반환하여 업로드되어있는 파일을 읽을 수 있게 해주는데, wads Memo에 들어가면 다음과 같이 메모 제목을 name으로 받아 파일을 읽는것을 볼수 있다.

![read-url](/assets/img/posts/fd/url.png)

`/upload`와 달리 `/read`는 "**..**"를 필터링하지 않기 때문에 /read?name=../filename(or directory) 처럼 디렉터리를 타고 올라가는게 가능하다.

### 익스플로잇
URL에 `http://host8.dreamhack.games:portnumber/read?name=../flag.py`를 입력하면 `/uploads/flag.py`를 읽어 *data*로 저장해서 출력해준다.
