## PWN-TOOLS
`pwn-tools`는 공격 스크립트를 손쉽게 작성할수 있게 도와주는 파이썬으로 만든 프레임워크이다.
주요 기능은 `네트워크 연동, 페이로드 생성, ROP가젯`으로 `로컬실행-process(), 원격 서버 접속-remote()`을 통해 취약한 프로그램과 상호작용한다.

```py
# pnw라이브러리에서 모든 모듈 불러오기
import * from pwn

#대상 서버 및 포트 연결 | 로컬에서 바이너리 파일을 실행하여 연결
p = remote('TARGET.com', PORT) | p = process('./test')

#데이터 수신
data = p.recvuntil(b'> ')

#데이터 송신및 상호작용 - sendline()은 개행문자를 포함하여 전송한다
p.sendline(b'A'*64)

# 상호작용 모드 전환
p.interactive()

# 디버깅 - 서버에 보낸 데이터와 서버로부터 받은 데이터를 16진수와 문자열로 보여준다
context.log_level='debug'

```

### How To Use
pwn-tools에서 사용하는 주요 기능들은 다음과 같다.
**연결및 통신**
* process('./target'): 로컬 환경의 바이너리 파일을 실행하여 연결
* remote('IP', Port): 원격 서버의 특정 포트로 TCP소켓 연결
* send(data), sendline(data): data를 보냄. sendline()은 줄바꿈 문자를 포함
* recv(n): 최대 n바이트 수신
* recvuntil(keyword): keyword(b'kkk')가 나타날때까지 데이터 읽기
* interactive(): 익스플로잇후 터미널 상호작용

### 분석
간단하게 pwn-tools를 이용해 문제서버에 원격으로 연결하여 데이터를 주고받아보자.
```py
from pwn import *

p = remote('host8.dreamhack.games', 23914)

data = p.recvline().decode()
print(data)
data = data.replace('+', ' ').replace('=', ' ')
print(data)

words = data.split()
print(words)

num1 = int(words[0])
num2 = int(words[1])

print(f"num1, num2, num1+num2 = {num1} + {num2} + {num1+num2}")
```

### Exploit
다음은 문제를 해결하기 위한 익스플로잇 코드이다.

remote()로 대상 서버와 연결한 후에 데이터를 불러읽어 디코드하고 필요없는 `+`, ` `를 공백으로 치환하고 `split()`으로 data의 문자를 배열로 저장한 후에 더해야할 두 숫자를 `num1`, `num2`로 저장한 후에 합을 보내도록 한다.
```py
from pwn import *
context.log_level = 'debug'

p = remote('host8.dreamhack.games', 23914)

for i in range(50):
    data = p.recvline().decode()
    data = data.replace('+', ' ').replace('=', ' ')
    words = data.split()
    print(words)

    num1 = words[0]
    print(f"num1: {num1}")

    num2 = words[1]
    print(f"num2: {num2}")

    result = int(num1) + int(num2)
    print(f"result: {result}")

    p.sendline(str(result).encode())
    print(f"Sent: {result}")

p.interactive()
```
