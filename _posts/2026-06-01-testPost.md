4. 최종 결과 설명

```python
from pwn import *
context.log_level = 'debug'

p = remote("host.dreamhack.games", 포트번호)

target_addr = 0x00000000  # 목표 주소

p.recvuntil(b'프롬프트 문자열')

payload  = b""            # 페이로드 구성
payload += b"A" * 00      # 버퍼 채우기
payload += p32(target_addr)

p.send(payload)

p.recvuntil(b'프롬프트 문자열')
p.sendline(b"입력값")

p.interactive()
```
