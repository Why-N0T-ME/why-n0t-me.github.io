## 고전 암호분석
### 1. 시저암호와 비제네르암호

#### 시저암호 (Caesar Cipher)

시저암호는 `평문(P)`을 `키값(k)`만큼 밀어서 `암호문(C)`을 생성한다. 예를 들어 P: HELLO, k=3이면 C: KHOOR이 된다.

시저암호는 모든 글자를 같은 k만큼 미는 **단일 치환 암호**라서 해독이 쉽다는 단점이 있다.

- **전수조사**: 키값의 경우의 수가 k=0(변화 없음)을 제외하면 25가지뿐이라 모두 대입해 볼 수 있다.
- **빈도분석**: 글자의 빈도 분포가 모양 그대로 k칸 이동할 뿐이라, 언어의 통계적 특성이 유지된다. 평문에서 가장 많은 글자가 E라면 암호문에서 가장 많은 글자와의 차이로 k를 추정할 수 있다.

#### 비제네르암호 (Vigenère Cipher)

비제네르암호는 **다중 치환 암호**다. `평문(P)`의 길이만큼 `키워드(keyword)`를 반복해서 늘어놓고, 각 평문 글자를 대응하는 키워드 글자의 알파벳 인덱스(A=0, B=1, …, Z=25)만큼 밀어낸다. 즉 글자마다 시저암호의 키가 달라진다.

P: HELLO, keyword: JB라면 다음과 같이 암호화가 진행된다.

```text
P: HELLO
K: JBJBJ
C: QFUMX
```

H(7)+J(9)=16 → Q, E(4)+B(1)=5 → F처럼 계산한다.

같은 평문 글자가 서로 다른 글자로 바뀌기 때문에 암호문 전체의 빈도 분포는 평평해지고, 단순 빈도분석이 통하지 않아 시저암호보다 비교적 안전하다.

하지만 키 길이를 $m$이라 할 때 암호문을 $m$개의 묶음으로 나누면(1번 묶음은 1, $m$+1, 2$m$+1번째 글자처럼 i번째, i+$m$번째, … 글자끼리) 각 묶음은 같은 키 글자 하나로 민 시저암호가 된다. 따라서 `일치지수(IC)`로 `키 길이(m)`를 추정한 뒤 묶음마다 빈도분석을 하면 키를 찾을 수 있어 위험하다.

#### 현대 암호와의 비교

고전 암호는 현재 실사용되지 않고 학습·CTF 용도로 다룬다. 현대 암호는 대칭키로 AES(국내는 ARIA, LEA) 같은 블록암호를, 공개키로 RSA나 타원곡선암호(ECC)를 쓴다. 키 공간이 $2^{128}$ 이상이라 전수조사가 불가능하고, 암호문에 평문의 통계적 특성이 남지 않도록 설계되어 있다.

### 2. 암호문을 시저 / 비제네르 암호로 구분하여라

암호문을 읽어 IC를 계산하고 그 값을 기준으로 어떤 텍스트파일이 시저 혹은 비제네르 암호로 암호화한 파일인지 판단한다. 판단하는 프로그램은 Python으로 간단히 작성하였다.

#### 일치지수(IC)

IC는 텍스트에서 무작위로 두 글자를 뽑았을 때 그 둘이 같은 글자일 확률이다.

$$
IC = \frac{\sum_{i=0}^{25} n_i (n_i - 1)}{N(N-1)}
$$

$N$은 전체 글자 수, $n_i$는 알파벳 $i$(A=0 ~ Z=25)의 등장 횟수이다.

- 영어 평문: 약 0.067. E, T 같은 일부 글자에 빈도가 쏠려 있어서 같은 글자가 뽑힐 확률이 높다.
- 무작위 글자: 약 0.038 (1/26). 분포가 평평하다.
- 시저암호: 글자 이름만 바뀔 뿐 각 글자의 등장 횟수는 그대로라서 IC가 평문과 같은 약 0.067로 유지된다.
- 비제네르암호: 서로 다르게 이동한 분포가 섞여 IC가 떨어진다. 키 길이가 2만 되어도 약 0.053이고, 길어질수록 0.038에 가까워진다.

그래서 시저(약 0.067)와 비제네르(약 0.053 이하) 사이인 **0.060을 기준값**으로 잡았다. 0.060 이상이면 시저, 미만이면 비제네르로 판별한다.

#### 코드

```python
## 문제 2 - IC를 구해 암호문이 Caesar Cipher인지 Vigenere Cipher인지 판단
import string
import sys

def get_IC():
    q = input("ciphertexts1.txt(c1) / ciphertexts2.txt(c2) \nSelect: ")
    if q == "c1":
        text = "ciphertexts1.txt"
    elif q == "c2":
        text = "ciphertexts2.txt"
    else:
        print("파일명이 잘못되었습니다.")
        sys.exit()

    with open(text, "r", encoding="utf-8") as f:
        ct = f.read()

    # 암호문 내용을 ct로 저장 (A~Z 대문자만 남김)
    ct = "".join(c for c in ct.upper() if "A" <= c <= "Z")
    N = len(ct)

    ni = {char: 0 for char in string.ascii_uppercase}

    # print(N): 암호문의 총 길이
    for char in ct:
        if char in ni:
            ni[char] += 1
    # print(ni) 잘 세는지 확인
    alphabet_list = list(ni.keys())  # ['A', 'B', ... 'Z']
    Sum = 0
    for i in range(26):
        char = alphabet_list[i]      # i번째 알파벳을 가져옴
        Sum = Sum + (ni[char] * (ni[char] - 1))
    IC = Sum / (N * (N - 1))

    print(f"{text}의 IC값: {IC:.3f}")
    return IC

def WhichCipher():
    IC = get_IC()
    if IC >= 0.060:
        print("<<Caesar Cipher>>")
    else:
        print("<<Vigenere Cipher>>")

WhichCipher()
```

##### 카이제곱 검정 및 키값 결정

###### 적합도 검정
적합도 검정이란 관측한 데이터의 분포가 기대한 분포와 얼마나 맞는지 재는 통계적 방법이다. 암호분석에서는 보통 카이제곱(χ²) 적합도 검정을 사용한다. 값이 작을수록 영어 분포와 비슷하단 의미다.

$$
X^2(k) = \sum_{i=A}^{Z} \frac{\left(\mathrm{freq}(P_i) - \mathrm{freq}(N_i)\right)^2}{\mathrm{freq}(N_i)}, \quad P_i = \mathrm{DEC}(C_i, k)
$$

- $k$: 복호화에 사용한 키 (0~25)
- $P_i$: 암호문을 키 $k$로 복호화한 텍스트에서 알파벳 $i$
- $\mathrm{freq}(P_i)$: 복호화한 텍스트에서 알파벳 $i$가 실제로 나온 횟수
- $\mathrm{freq}(N_i)$: 영어 빈도표로 계산한 알파벳 $i$의 예상 출현 횟수 (전체 글자 수 × 영어에서의 비율)

$X^2(k)$가 가장 작은 $k$가 영어 분포와 가장 비슷하므로 정답 키 후보가 된다.

###### 키 구하기

![alpha-freq](/assets/img/posts/Crypto/26대회/고전암호분석/알파벳빈도.png)


```python
import string

def freq():
    with open("ciphertexts1.txt", "r", encoding="utf-8") as f:
        ct = f.read()
        ct = "".join(c for c in ct.upper() if "A" <= c <= "Z")

    results = {}    # {키: 그 키로 복호화한 결과의 ni 딕셔너리}

    # k = 1 - 25 전수조사
    for k in range(1, 26):
        plain_text = ""
        for char in ct:
            # 왼쪽으로 k칸 이동
            decrypted_char = chr((ord(char) - ord("A") - k) % 26 + ord("A"))
            plain_text += decrypted_char

        ni = {char: 0 for char in string.ascii_uppercase}
        for char in plain_text:
            if char in ni:
                ni[char] += 1
        results[k] = ni

    return results

# [표 1] 영어 알파벳 빈도표 (%)
ENG = {"A": 8.17, "B": 1.5, "C": 2.78, "D": 4.25, "E": 12.7, "F": 2.23,
       "G": 2.02, "H": 6.09, "I": 6.97, "J": 0.15, "K": 0.77, "L": 4.03,
       "M": 2.41, "N": 6.75, "O": 7.51, "P": 1.93, "Q": 0.1, "R": 5.99,
       "S": 6.33, "T": 9.06, "U": 2.76, "V": 0.98, "W": 2.36, "X": 0.15,
       "Y": 1.97, "Z": 0.07}

def KAI():
    results = freq()                    # 모든 키의 복호화 결과 빈도
    N = sum(results[1].values())        # 전체 글자 수 (키와 상관없이 같음)

    # 영어 빈도표(%)를 이 암호문의 글자 수에 맞춘 예상 출현 횟수로 변환
    expected = {char: N * ENG[char] / 100 for char in string.ascii_uppercase}

    best_k = None
    best_x2 = None
    for k in range(1, 26):
        ni = results[k]
        x2 = 0
        for char in string.ascii_uppercase:
            x2 += (ni[char] - expected[char]) ** 2 / expected[char]

        print(f"Key {k:2d}: X^2 = {x2:.1f}")
        if best_x2 is None or x2 < best_x2:
            best_x2 = x2
            best_k = k

    print(f"\n가장 작은 X^2: Key {best_k} ({best_x2:.1f})")

KAI()
```
