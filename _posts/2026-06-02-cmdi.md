## Concept

### 서비스 분석
```python
@APP.route('/ping', methods=['GET', 'POST'])
def ping():
    if request.method == 'POST':
        host = request.form.get('host')
        cmd = f'ping -c 3 "{host}"'
        try:
            output = subprocess.check_output(['/bin/sh', '-c', cmd], timeout=5)
            return render_template('ping_result.html', data=output.decode('utf-8'))
        except subprocess.TimeoutExpired:
            return render_template('ping_result.html', data='Timeout !')
        except subprocess.CalledProcessError:
            return render_template('ping_result.html', data=f'an error occurred while executing the command. -> {cmd}')

    return render_template('ping.html')
```
{: file="ping.py"}

`/ping`을 보면 cmd에 host를 입려받아 POST요청을 보내고 output에서 해당 cmd를 쉘로 실행하고 그 출력 결과를 출력한다.

1. 기능 정상작동
`/ping`탭에 Host를 입력하는 입력필드가 있다. 8.8.8.8을 입력하면 정상적으로 ping이 실행되어 8.8.8.8로 3번 핑을 보낸 결과를 렌더링한다.

2. Command Injection
host값을 받아오는데 입력값을 **xxx.xxx.xxx.xxx** 처럼만 입력이 가능하도록 강제하지 않고 필터링 또한 존재하지 않으므로 Command Injection을 시도할수 있을 것이다.

쉘을 실행할때 `; |` 같은 특수문자를 사용할수 있는데, `;`를 사용할 경우 이 문자 앞에 있는 쉘이 실행된 후에 뒤에 오는 쉘을 실행하여 여러줄의 쉘을 한줄로 실행할 수 있다. 또, `|`의 경우에는 이 문자 앞에서 실행한 쉘의 결과값을 저장한 상태에서 뒤에 오는 쉘을 사용한다.
```sh
echo "Hi"; echo "I'm Topiary"
echo "Hello, Groot" | tee Greet.txt ; cat Greet.txt
```
{: file="쉘.sh"}
```sh
Hi
I'm Topiary

Hello, Groot
Hello, Groot
```

{: file="ping.sh"}
쉘의 실행 결과는 wsl에서 쉘을 실행하여 얻은 결과이다. flag.py를 임의로 작성하여 cat으로 읽을수 있도록 했기에 이 글을 읽는 당신들은 *testFlag*가 뜨지 않고 *No such file or directory*가 뜨거나 다른 오류메세지가 뜰 것이다. 이런 쉘 실행 결과를 보인 이유는 우리가 조작할 페이로드의 모습을 보이기 위함이다.
ping에 **8.8.8.8"; cat "flag.py**를 입력하면 드림핵 서버에서는 
```sh
$ ping -c 3 "8.8.8.8" ; cat "flag.py"
```

위 코드처럼 쉘이 실행되고 flag.py의 내용을 읽어 화면에 출력해줄 것이다.
